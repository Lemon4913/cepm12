# ส่วนที่ 2 ข้อมูลโครงการวิจัย

**1. หลักการและเหตุผล**

ตลาดท่านา ตั้งอยู่ที่ตำบลนครไชยศรี อำเภอนครไชยศรี จังหวัดนครปฐม เป็นตลาดชุมชนริมแม่น้ำนครไชยศรีที่มีอายุกว่า 140 ปี มีรากฐานมาตั้งแต่สมัยรัชกาลที่ 1 และพัฒนาเป็นชุมชนค้าขายสำคัญในสมัยรัชกาลที่ 5 ชื่อ "ตลาดท่านา" มีที่มาจากการที่บริเวณนี้เคยเป็นท่าเรือสำหรับซื้อขายและขนส่งข้าวเปลือก ข้าวสาร ด้วยทำเลติดริมน้ำที่สะดวกต่อการคมนาคมทางเรือ

อย่างไรก็ตาม จากการลงพื้นที่สำรวจและสัมภาษณ์ผู้นำชุมชนรวมถึงพ่อค้าแม่ค้าในตลาด พบว่าในปัจจุบันตลาดท่านาประสบปัญหาจำนวนนักท่องเที่ยวลดลงอย่างเห็นได้ชัด สาเหตุหลักเกิดจากการย้ายออกของร้านอาหารชื่อดังในพื้นที่ ประกอบกับปัญหาการขาดระบบนำทางและข้อมูลสำหรับนักท่องเที่ยว ทำให้ผู้มาเยือนไม่ทราบว่าแต่ละร้านจำหน่ายสินค้าประเภทใด ไม่มีเส้นทางแนะนำไปยังจุดที่น่าสนใจ และไม่สามารถเข้าถึงเสน่ห์ที่ซ่อนอยู่ภายในชุมชนได้อย่างเต็มที่

แม้ที่ผ่านมาจะมีความพยายามปรับปรุงพื้นที่ เช่น การวาดภาพจิตรกรรมฝาผนังเพื่อสื่อถึงเอกลักษณ์ของตลาด การติดตั้งตู้อาหารปลาเพื่อส่งเสริมกิจกรรมสำหรับนักท่องเที่ยว และการจัดการพื้นที่จอดรถโดยหน่วยงานและผู้นำชุมชน แต่ยังขาดระบบที่เชื่อมโยงประสบการณ์การท่องเที่ยวในภาพรวม

โครงการนี้จึงเสนอให้นำเทคโนโลยีเข้ามาแก้ไขปัญหาดังกล่าว ด้วยการพัฒนาแผนที่ดิจิทัลของตลาดชุมชน และออกแบบกิจกรรม Walk-Rally ที่ใช้ระบบสแกน QR Code เพื่อเพิ่มการมีส่วนร่วมของนักท่องเที่ยว กระตุ้นให้สำรวจตลาดอย่างครบถ้วน และสร้างโอกาสทางการค้าให้แก่ผู้ประกอบการในชุมชนอย่างยั่งยืน

**6. การประเมินผล**

1. ตัวชี้วัดเชิงปริมาณ
   1. จำนวนจุด check-in ที่ติดป้าย QR code
   2. จำนวนผู้เข้าใช้งานเว็บแอปพลิเคชัน
2. ตัวชี้วัดเชิงคุณภาพ
   1. ผลประเมินความพึงพอใจผู้ใช้เว็บแอปพลิเคชัน
   2. ความคิดเห็นของผู้ใช้เว็บแอปพลิเคชัน
   3. ผลการสัมภาษณ์ผู้ประกอบการในพื้นที่ตลาดท่านา

**7. ผลลัพธ์ที่คาดหวัง**

1. เพื่อเพิ่มการกระจายรายได้สู่ร้านค้าในชุมชน โดยมุ่งเน้นให้นักท่องเที่ยวและผู้มาใช้บริการใช้เวลาภายในตลาดท่านานานขึ้น โดยอาศัยความสนใจของนักท่องเที่ยวที่มีต่อตลาดท่านาเป็นจุดแข็ง เพื่อกระตุ้นการจับจ่ายใช้สอยและกระจายรายได้สู่ร้านค้าในชุมชนอย่างทั่วถึง
2. เพื่อพัฒนาระบบนำทางและอำนวยความสะดวกภายในตลาด โดยพัฒนาเครื่องมืออำนวยความสะดวกด้านการสัญจรและนำทางภายในตลาด เช่น แผนผังตลาด ระบบ QR Code ประจำจุดต่าง ๆ และข้อมูลพิกัดร้านอาหาร เพื่อให้ผู้มาเยือนสามารถสำรวจพื้นที่ได้อย่างครบถ้วน ทั่วถึง และไม่สับสน อีกทั้งยังใช้เป็นเครื่องมือวัดผลการกระจายตัวของนักท่องเที่ยวภายในพื้นที่ได้อีกด้วย
3. เพื่อส่งเสริมการท่องเที่ยวเชิงประวัติศาสตร์และวัฒนธรรม โดยสื่อสารและถ่ายทอดรากลึกความเป็นมาของตลาดท่านาผ่านเนื้อหาเชิงประวัติศาสตร์ วัฒนธรรม และวิถีชีวิตชุมชน เพื่อสร้างคุณค่าและประสบการณ์ที่มีความหมายให้แก่ผู้มาเยือน

**8. แผนความยั่งยืนของโครงการ**

วางแผนให้โครงการนี้สามารถนำไปใช้ได้จริงในระยะเวลา 1–2 ปี เพิ่มจำนวนนักท่องเที่ยวและยอดขายให้ได้มากขึ้นในทุกๆ ปี เมื่อระบบเริ่มคงที่ จะมอบโอนความรับผิดชอบให้กับเทศบาล หัวหน้าชุมชนและคณะกรรมการมูลนิธินครไชยศรี
